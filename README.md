# ETL Pipeline Project

## Overview
This repository contains my ETL (Extract, Transform, Load) project completed for my data science coursework. 
The project demonstrates how to extract data, clean and transform it, and prepare it for analysis.

## Files in This Repository

### 📘 Wieting_final.ipynb
This Jupyter Notebook contains the full ETL workflow, including:
- Data extraction
- Data cleaning and transformation
- Exploratory analysis
- Final outputs

### 📄 Wieting_final_projectreport
This is the written project report summarizing:
- The problem statement
- Methods used
- Results and findings
- Conclusions and next steps
